## 授权「多设备共享」方案调研（用户提问）

**关键事实（官方 doc 2057「token 有效期&续期」+ doc 2096「刷新 token」）**：
- access_token 1 天、refresh_token 30 天
- **每次刷新都会生成新的 access_token 和新的 refresh_token，老的立即失效** —— 轮换制，不是续期制
- → 同一份 token 复制到多台设备各自使用会**互相踢下线**（谁先刷新谁有效）
- → 多设备共用的正解：**共享一个后端**（一台主机跑后端，token 单点刷新；其他设备用浏览器访问）

**代码现状**：
- `apps/server/src/main.ts:77` `app.listen(port, '127.0.0.1')`，上一行注释明确写着「只监听本机：凭证与 token 都在这个进程里，绝不能暴露到局域网」
- 但 `main.ts:40` 注释已预留「Electron 与局域网部署都走这条路」——前端同源托管，本身就是普通 Web 应用
- 后端**零鉴权**（全仓 grep 无 CanActivate / UseGuards / apiKey）→ 一旦监听 0.0.0.0，局域网内任何人
  可调 `/api/manage/*`（改出价、改预算、改状态）与 `/api/plan/tasks`（真实建计划）→ **必须加访问口令**

**给出的三个方案**（已用对比图向用户说明，等待用户选择后再实施）：
1. 共享后端（推荐）：加「局域网共享」开关（监听 0.0.0.0）+ 访问口令 + 界面显示访问地址/二维码
2. 授权包导出/导入：适合换电脑迁移或重装；注意同一时刻只应有一台设备在跑（否则 refresh_token 互踢）
3. 部署到云服务器：方案 1 的异地版

## 局域网共享授权已实现（0.6.0，2026-10-08 16:50）

用户选择方案：**共享一个后端（局域网）**。已完整实现、真实验证、打包交付。

### 实现（三层）
1. **后端**
   - `ShareConfig` 表（enabled / passwordHash scrypt 哈希 / updatedAt）+ 迁移 `20261008000000_share_config`
   - `modules/system/share.service.ts`：配置读写、scrypt 口令哈希与校验（失败限流 10 次/5 分钟）、
     枚举局域网 IPv4、`isLoopback()`、重启标记
   - `modules/system/share.guard.ts`：**全局 AccessGuard（APP_GUARD）**——
     本机回环无条件放行；`@SharePublic()` 仅探针/登录两处；未开共享 → 403 SHARE_DISABLED；
     已开共享 → 校验 `x-wkbd-key` 请求头，不通过 401 SHARE_AUTH_REQUIRED
   - system 接口：GET/POST `/api/system/share`（**仅本机**，LOCAL_ONLY）、
     POST `/share/probe`（免鉴权）、POST `/share/verify`（登录）、POST `/restart`（仅本机，写标记后退出）
   - `main.ts` 启动时读配置决定监听 `0.0.0.0` 或 `127.0.0.1`，并写 `WKBD_BIND_LAN` 供 restartRequired 判断
2. **Electron main.js**
   - 后端退出时检查 `userData/.restart-intent`：有标记 → 静默重新 startServer() 并 loadURL 新端口；
     无标记 → 原有错误弹窗。顺带修了「正常退出也弹后端异常退出」的隐患（quitting 标志）
3. **前端**
   - `client.ts`：自动附 `x-wkbd-key`（localStorage）；口令失效自动清除并广播 `onShareAuthRequired`
   - `components/ShareGate.tsx`：口令门（本机直接放行；未开共享显示指引；需要口令时输入验证）
   - `pages/setup/ShareCard.tsx`：接入设置页第 ④ 卡片——开关、口令、局域网地址列表+复制、
     「保存并重启生效」（轮询健康检查通过后自动 reload）

### 实测结论（全部真实请求验证）
- 共享关闭：监听 127.0.0.1，局域网地址**连接都建立不了**；本机一切正常
- 开共享不给口令 → 400；口令 <4 位 → 400；正常开启 → restartRequired=true
- 重启后监听 0.0.0.0，日志打印局域网地址
- 局域网访问：探针免鉴权返回 requiresKey=true；业务接口无口令 401；错口令 401；
  对口令 200；**局域网读/改共享配置 → 403 LOCAL_ONLY**（防止外部设备把自己加进白名单）
- 静态页与资源不受守卫影响（口令门才能渲染出来），数据接口全部拦住
- 本机访问永远不需要口令（回环放行）
- 重启接口：写标记 → 600ms 后退出；Electron 看到标记静默拉起
- **无头 Edge 截图实证**：局域网地址打开 → 口令门界面；主机端 `/#/setup` → 共享卡片完整

## 0.6.1：搜索快投扩词修复 + 非局域网设备自行授权（2026-10-08 19:05）

### 一、修复 401000「搜索快投必须开启智能扩词」（其他共享用户真实撞到的错）
- **根因**：平台对 `quick_search` 有跨字段硬校验——开启快投必须同时下发 `extend_search=true`（布尔，
  官方 doc 2262 只写"选填默认 false"，实际强校验）。而前端把「智能扩词」开关只放在
  adType=1 分支，快投用户（adType=0）根本拿不到它 → 必然撞错
- **修复**：`plan.mapper.ts` 提取 `quickSearch` 变量，快投时无条件 `payload.extend_search = true`；
  搜索广告仍按用户开关。esbuild 直跑 5 项断言全过（快投开/关、搜索广告开/关、追投）
- 前端 `PlanCardMode.tsx`：提交行时快投场景同步置 searchExtend=1；快投开关下加「已自动开启智能扩词
  （平台强制）」提示；摘要「广告类型」显示「展示广告 · 搜索快投（含智能扩词）」
- ⚠️ 历史任务 payload 是冻结的——**重试失败任务走 refreshFailedPayloads 重建后才会带上扩词字段**

### 二、非局域网设备自行授权（共用软件的另一半）
用户诉求：局域网已可共享后端；不在同一网络的人也要能在自己电脑上自行授权自己的账户。
根因：开发者应用凭据（app_id/secret）只在主机库，异地设备拿不到就无法走授权。

1. **授权能力对共享用户开放**：
   - `share.guard.ts` 新增 `@LocalOnly()` 装饰器（守卫内先于口令检查拦截非回环请求 → 403 LOCAL_ONLY）
   - `settings.controller` POST/DELETE /app 加 LocalOnly——共享用户**能读**（脱敏）、**不能改**凭据
   - 前端 SetupPage 用 `/api/system/share/probe` 的 `isLocal` 判断身份：远端时第①卡片表单禁用+
     说明"由主机统一配置"，第②③卡片（生成授权链接/手工兑换/对齐）完全可用 → 远端用户
     用自己快手账号授权，账户汇入同一工作台
2. **手工兑换增强**：`parseTicket()` 支持粘贴**整条回调 URL**（自动提取 auth_code + state）——
   state 能还原授权入口/方式，识别账户更准。本项目回调落公网中转域名（pzds.com），
   粘整条地址是最自然的操作
3. **应用配置迁移包**（异地设备的正解）：
   - `settings.service` exportPortable/importPortable：`WKBD-CONFIG-V1.<salt>.<iv>.<tag>.<body>`，
     scrypt+AES-256-GCM 用**迁移口令**加密（与 master.key 无关，跨机可还原）；
     **只含 app_id/secret/redirect_uri/scopes，绝不含 token**（token 轮换制，复制互踢）
   - 路由 POST /api/settings/app/export|import，均 LocalOnly（secret 不能让共享用户带走）
   - 前端 `setup/PortableConfig.tsx`：导出（口令→生成→下载/复制）+ 导入（粘贴+口令→覆盖本机）
   - 所有校验错误统一 BadRequestException（400），不再 500

### 真实验证（临时库 = 真实库副本 + 独立空库）
- mapper 5/5；本机导出 201（payload 348 字符）；局域网带正确口令调 export/import/POST app → 全 403 LOCAL_ONLY；
  局域网 GET /app → 200 且 secret 脱敏；probe isLocal 正确；错口令/坏格式/短口令/空 payload → 全 400

- 远端授权链路：带口令 GET /api/oauth/authorize-url → 200 出链接（state=xxx.LUOPAN.USER）；无口令 401；
