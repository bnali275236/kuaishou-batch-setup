## 黑窗口复现 + 双守护互抢（本次根治）
- 现象：白底黑窗（Windows Terminal 空白标签，标题是 node.exe 路径）又出现。
- 根因1：Windows 11 默认终端是 Windows Terminal，`Start-Process -WindowStyle Hidden` 被 WT 忽略 → 隐藏后台进程实际弹了 WT 窗口。改用 `spawn(execPath, ['--hidden'], {detached:true, windowsHide:true, stdio:'ignore'})`（CreateProcess 带 CREATE_NO_WINDOW，进程不申请控制台，WT 无机可乘）。实测：隐藏进程存活、无 WT/conhost 窗口。
- 根因2（更严重）：takeOverPort 只看端口是否监听。新实例在老实例「进程已起、服务未就绪」的空窗里启动 → 端口没监听 → 也拉一个守护 → 两守护互抢 7801，抢不到者每 60s 崩一次（launcher.log 里「异常退出 code=1」连续 9 次）。修复：先读 lock，lock 主人还活着就轮询等它把服务拉起（最多 40s），健康就复用退出；40s 还不健康才 killTree(lockPid) 接管。
- 后端 spawn 改 `windowsHide:true` + stdio 落盘 `.runtime/server.out.log` / `server.err.log`（原来 inherit 到隐藏控制台，崩溃无日志）；ioFds 复用前先关闭，日志 >5MB 清空。
- 现场处理：kill 掉重复守护 5044、关掉残留 WT 窗口、服务由新代码重新拉起（pid 20660 → server 33700），HTTP 200。
