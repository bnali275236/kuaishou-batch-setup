## 桌面快捷方式：从「网址书签」升级为「点一下就启动服务」
- 用户反馈：桌面「快手投放工作台」图标（紫闪电）点了打不开——它其实是 `快手投放工作台.url`，内容只有 `URL=http://127.0.0.1:7801/`，纯网址书签，服务没起就是死链。
- 目标：双击 = 执行 启动网页版.cmd（服务在跑则复用）+ 自动开浏览器。
- 踩坑：① 老式 Shell COM 实例化被安全策略禁；② 纯 Node 手写最小 lnk（只有 Header + LinkInfo + StringData、无 IDList）→ Shell 提示「没有应用程序与此操作的指定文件有关联」，Win11 的 Shell 必须有 LinkTargetIDList；③ 系统自带 lnk（msinfo32 / services / regedit / mstsc）大多 HasTargetIDList=false，靠 PropertyStoreDataBlock(0xA0000009) 里的 System.Link.TargetParsingPath 解析目标，比 IDList 更难手写。
- 正解：**pylnk3**（纯 Python，无 COM）。`python -m pip install pylnk3`（清华源没有该包，用官方源）→ `pylnk3.for_file(命令解释器路径, arguments='/c "…启动网页版.cmd"', work_dir=ROOT, icon_file=tools/icon.ico, window_mode='Minimized')` → 577 字节 lnk，IDList 链 MyComputer → C:\ → Windows → System32 → 目标 exe 完整，ShowCmd=7（窗口最小化，转后台后自动消失）。
- 产物：`tools/make-desktop-lnk.py`（可重跑）；`tools/lnk-dump.cjs`（解析任意 lnk，排障用）；桌面旧 .url 已删除；Node 版 make-desktop-lnk.cjs 无效实现已删。
- 验证：结束守护进程树 → Shell 触发桌面 lnk → 日志出现「启动器就绪 pid=36752 / 服务就绪，自动打开浏览器」，root HTTP 200。注意健康检查路径是 `/api/system/health`（`/api/health` 是 404）。
