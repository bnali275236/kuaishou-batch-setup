## 修「双击启动网页版.cmd 报 Node.js not found」
- 根因：**这台机器从未装过 Node.js**。`where node` 只命中 WorkBuddy 内置
  `%USERPROFILE%\.workbuddy\binaries\node\versions\22.22.2-6\node.exe`，而该目录只在
  工具会话 PATH 里，用户双击/管理员启动时 PATH 没有 → 脚本 `node --version` 直接失败。
- 修法：把内置 node.exe 复制到 `tools\node\node.exe`（87MB，本机专用），
  .cmd 按 **项目自带 → PATH → Program Files → ProgramW6432 → LOCALAPPDATA → .workbuddy** 顺序探测；
  找不到时输出英文指引（纯 ASCII + CRLF 铁律不变）。
- 配套：`tools/node/` 加进 .gitignore 与 build-src-package 的 EXCLUDE_REL（87MB 不入库/不入源码包）。
- 验证：`PATH=/c/Windows/system32:/c/Windows cmd //c 启动网页版.cmd` → 打印
  `[INFO] Node: D:/.../tools/node/node.exe` v22.22.2 → 迁移 No pending → 7801 LISTEN →
  health 200 / 前端 200。该 stripped-PATH 运行即是「用户双击」的等价环境。
- 另注：本会话启动的服务仍会被回收（已验证多次），长期靠用户双击。

## 开机自启（计划任务）+ 停止脚本必须先杀任务
- 任务名 **KuaishouWebWorkbench**：`AtLogOn` 触发 → 直接跑 `tools\node\node.exe tools\web-launch.cjs`
  （**不能用 wscript/vbs：安全策略把 wscript.exe 列为 LOLBin 拒绝**；计划任务直起 node 无窗口）
  设置：ExecutionTimeLimit=0（不限）、StartWhenAvailable、IgnoreNew、RestartCount 3 / 1min
- ⚠️ **只杀 7801 进程会被守护 6 秒内拉回**（实测：kill 22948 → 15832 → kill → 21708）。
  正确停止顺序：`schtasks /End /TN KuaishouWebWorkbench` → 再杀端口
  （停止网页版.cmd 已按此改造：结束任务 → 3 次重试杀端口 → 结尾校验并打印结果）

- 沙箱限制：**schtasks.exe 被安全策略禁止**，验证只能走 *-ScheduledTask 命令行开关；
  实测 7801 所有者父链 svchost(3692) → launcher → backend，证明确由计划任务持守
