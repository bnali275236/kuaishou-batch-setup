# 2026-10-09

## 整理源码迁移包（v0.6.1）

需求：把工程源码整理成可迁移到其他电脑继续开发/优化的包。

产出：
- `快手投放工作台-源码-v0.6.1.zip`（24.8 MB，155 个文件，解压后单层目录）
- `源码迁移与开发说明.md`（仓库根目录，随包分发；新环境跑起来/打包/踩坑三合一）

打包工具固化（可复用，改动版本号只需改 `PKG_NAME`）：
- `tools/src-package/build-src-package.cjs` → 整理到 `.tmp-pack/<包名>/`
- `tools/src-package/build-zip.cjs` → 打 zip 到仓库根

排除清单（三类）：构建产物（`node_modules` / 各 `dist` / `release` / `resources/server|web` staging）、
密钥与本机数据（`apps/server/.env`、`.data/` 含 `master.key` 与授权密文）、临时文件（`*.log`、
`.tmp-*`、`vite.config.ts.timestamp-*.mjs`、截图）。

有意保留：
- `apps/electron/resources/redist/vc_redist.x64.exe`（25 MB，main.js 用作 VC++ 运行库兜底，是**源资产**不是产物）
- `.workbuddy/memory/`（踩坑全集，对新环境继续开发价值高）

归集：把散落在临时目录的开发资产搬进包内 `tools/`（`platform-probe` / `electron-diag` / `logic-verify`）。

两个设计要点：
1. **重建会丢弃手工放进包内的文件** —— 说明文档因此改放仓库根目录，由 walk 自动收录；往包里加东西要放仓库里，别直接写进 `.tmp-pack/<包名>/`。
2. **zip 输出必须排除自身**（`.zip` 已加入排除后缀），否则重跑时新包会把旧 zip 一起打进去（自引用）。
