## 第二十三轮（桌面版他机启动失败修复 + 重打包，2026-09-28）

**他机报错**：安装后启动弹「启动失败：健康检查超时：后端未能启动」（Electron 窗口能弹，后端没活到健康检查通过）。

**根因判断**：全新 Windows 缺 VC++ 2015-2022 运行库（msvcp140/vcruntime140），Prisma 查询/迁移引擎加载即崩 → 后端进程启动即退，而旧主进程在后端提前退出时仍傻等 60s 才报超时，且弹窗不含日志内容，无法远程排障。

**修复（apps/electron/main.js）**：
1. ensureVcRuntime：启动前检测 System32 三个 dll，缺失则用包内 resources/redist/vc_redist.x64.exe（24.4MB，aka.ms 下载，随 extraResources 进包）通过 PowerShell Start-Process -Verb RunAs 静默安装（弹 UAC），装完复检。
2. startServer 改 Promise + fail-fast：后端进程在健康检查通过前退出 → 立即报错并附带 [server] 最近 15 行日志（环形缓冲 60 行），不再干等。
3. 健康检查超时 60s → 120s（慢机器/杀软扫描）。
4. 启动失败弹窗改 showMessageBox：错误原因 + VC 缺失提示 + desktop.log 最后 10 行 + 「打开日志文件」按钮；后端就绪后崩溃也有弹窗提示重启。
5. 迁移失败输出含 msvcp140/VCRUNTIME 时日志点明疑似缺运行库。

重打包：apps/electron `npm run desktop:pack`（全量构建含第 22 轮三改动）。

**打包结果**：release/快手投放工作台 Setup 0.1.0.exe（168.7MB，含 vc_redist 25MB）。electron-builder 收尾清 .nsis.7z 又撞 SAFE_DELETE_BULK 护栏 exit 1，但安装包已生成，不影响。本机实测：/S 静默安装覆盖旧版 → 启动 → 迁移应用（readOnly）→ 后端 7802 健康检查通过 → read-only 路由注册。注意：本环境工具调用结束时回收 GUI 测试进程，验证要在同一次调用内完成（Start-Process + Start-Sleep + 当场 Invoke-WebRequest）。安装目录是 %LOCALAPPDATA%\Programs\@wkbddesktop（appId 目录名，非 productName）。
