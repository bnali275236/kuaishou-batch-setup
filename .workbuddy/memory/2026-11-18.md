## 局域网共享排查（09:45）
- 现象：用户点了局域网共享、重启后其他设备仍进不来。
- 排查：netstat 显示监听 127.0.0.1、GET /api/system/share 返回 enabled=false → 根因一：**保存没成功**（launcher.log 显示 09:44 只有重启、库里开关仍是关的；正确操作是设置页点开关→点「保存并重启生效」一个按钮完成保存+重启）。
- 根因二：**Windows 防火墙无放行规则**——即使开了共享，其他设备的入站连接也会被拦。已用 netsh advfirewall（UAC 提权）加规则「KuaishouWebWorkbench 7801」：TCP 入站 7801，域/专用/公用全放行。
- 实测全链路：API 保存 enabled=true → 重启 → 0.0.0.0:7801 监听 → 本机走 LAN IP 172.16.16.47 probe 返回 requiresKey=true（口令门正常）。
- 教训：本机访问自己的 LAN IP 不经过防火墙入站过滤，验证防火墙必须用真实外部设备。
