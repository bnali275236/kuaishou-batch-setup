## 运维踩坑：本机系统代理会劫持 127.0.0.1
- 用 curl 验 7801 时返回 **HTTP 502**（不是服务挂了，是系统代理拦截 localhost 后转发失败）。判定服务是否在线必须加 `--noproxy '*'`，否则会误判成「后端已死」。
- 同理 `netstat | grep LISTENING | grep :7801` 偶尔抓空（时序/管道过滤问题），**以 `curl --noproxy` 的实际响应为准**。
- 会话后台任务跑 web-launch.cjs 会被回收（上报 exit 127/0），但实测服务常被重新拉起（PID 会变）。判断"是否可用"只看端口响应，不看后台任务状态码。
