### ⚠️ 授权已失效，需要重新授权

`AuthGrant` 只有 1 条：
- `id=5`，`authEntry=LUOPAN`，`authType=USER`
- `status = NEED_REAUTH`
- `lastError = 刷新 token 失败[402005]：refresh token错误`
- `createdAt = 2026-10-08 14:42:15`，`updatedAt = 2026-11-06 15:32:21`（**正好是本次打开应用、尝试刷新失败的时刻**）
- `refreshTokenExpiresAt = 2026-12-06 15:32:20` —— 注意这个值很像「刷新尝试时按 now+30d 写入」的产物，
  **不能当作真实有效期**，真实判据是平台返回的 402005
- `OauthAccount` 仍 206 条、全 ACTIVE，但那是本地旧清单，**token 已死，所有平台调用都会失败**

日志表现：`MapiGateway /rest/openapi/v1/report/account_report 第 N 次失败（TOKEN_INVALID：广告账户 grant:5 的 refresh_token 已失效，必须重新走授权流程）`，指数退避重试中。

**最可能的原因**：应用上次运行是 **2026-10-08 19:12**，之后近 **29 天**没启动过。
refresh_token 是 30 天轮换制（见 MEMORY.md「token 生命周期」），长期不用就直接失效；
不能排除是别处/另一台机器刷新过把这份踢掉（同日轮换制的经典坑）。
→ 教训：**桌面版不要长时间不启动**，超过约 3 周就该打开一次让它自动刷新，否则又要人工重新授权。

**修复动作（用户侧）**：应用内「账户管理」→ 重新授权，走**磁力罗盘**入口 + 授权页选「基于用户授权」，

## 修复：账户名称不随平台改名更新（124276386 事故）

（后续用户已重新授权，新凭证 grant #6 ACTIVE，实测 token 有效 —— 上节失效问题已由用户自行解决。）

根因（实测确认）：
- 本地名称回填 `backfillMissingNames()` 查询条件是 `WHERE accountName IS NULL` —— **只补缺失，永不更新已有名称**
- 账户对齐走的 `approval/list` 只回广告主 ID 不回名称，upsert 时 `accountName ?? undefined` 带不来新名
- 平台 `v1/advertiser/info` 实时返回新名（名称在 `user_name` 字段），代码取名顺序 user_name 优先没问题

修复（v0.6.2）：
- schema 加 `OauthAccount.nameSyncedAt` + migration `20261106000000_account_name_synced_at`
- `backfillMissingNames` 改两级队列：先补缺失，剩余配额刷 `nameSyncedAt` 超 24h 的已有名称账户（最旧优先）；拉取异常不写时间戳自然重试，「响应成功但无名称字段」也写时间戳防占配额
- 新增 `TokenService.refreshAccountName()` + 路由 `POST /api/oauth/accounts/:id/refresh-name`
- 账户页行操作新增「刷新名称」按钮（绕过 24h 门槛立即生效）
- 定时任务仍每 5 分钟一轮 max 100 → 全量账户 2~3 轮建立 nameSyncedAt 基线，之后每账户每天自动刷一次

验证：脚本直连桌面版 DB + master.key 解密调 advertiser/info 实测平台返回新名；tsc/vite 编译过；Setup 0.6.2.exe 打包成功（exit 1 为已知删除护栏误报），staging 校验迁移 SQL / nameSyncedAt / refresh-name 均在包内。

### 网页版启动脚本的两轮踩坑（重要，勿重犯）
1. 第一版 .cmd 内直接 set DATA_DIR=%APPDATA%\快手投放工作台 + 中文提示 → **GBK 控制台把中文读花**，
   变量静默失效，服务连到了 apps/server/.data（空开发库）且 WEB_DIST 丢失 → 前端 404。
   现方案：.cmd **纯 ASCII**，中文路径全部交给 `tools/web-launch.cjs`（Node 固定 UTF-8 解析）。
2. 文件是 LF 换行 → cmd 解析错位（报 `'ishou' 不是内部命令`，单词被截断）→ **必须 CRLF**。
   用 node 脚本 `replace(/\r\n/g,'\n').replace(/\n/g,'\r\n')` 转换后正常。
3. 已在 web-launch.cjs 内做迁移（spawnSync prisma migrate deploy，DATABASE_URL 指向桌面库），
   .cmd 只负责端口检测 + 调用。
4. 验证口径：health 200 + 前端 200 + 日志「数据目录 …AppData\Roaming\快手投放工作台」+ 127 账户。
