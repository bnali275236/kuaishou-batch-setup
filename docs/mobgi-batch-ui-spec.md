## 6. 与我们向导（PlanCardMode）的差距清单

1. **摘要行+编辑抽屉范式**：mobgi 主页面 13 行摘要可一眼全览；我们目前是全展开表单 → 应把「广告组基本信息」改成摘要卡+编辑抽屉
2. **投放模式大卡**（常规/全自动+优选角标）、**投放位置三 tab**（智能优选/快手主站/快手联盟）+ 分组芯片
3. **最大转化禁用态**：预算不限时置灰+popover 提示（我们目前是警示条+自动切预算，可补禁用交互）
4. **优化目标三芯片 + 转化目标/深度转化目标双下拉**（激活/付费/首日ROI(24h)/7日ROI/7日付费次数；深度：无/付费/自然次日次留存/首日ROI）——我们已做双出价，但下拉选项要补齐这套
5. **出价分配规则（全部相同/按账户分配）+ 出价方式（固定/随机/阶梯）+ 出价范围**：mobgi 用 12~14 区间，预览时每条链路按阶梯生成 12→12.071→…→14（这正是用户之前问的「出价方式」的真正用法，且作用于**预览生成阶段**而非 UI 装饰）
6. **HarmonyOS 平台**（mobgi 有，快手 API 文档没有——照文档口径我们仍不放，或做成仅 UI）
7. **素材分配**：平均分配/全账户使用/分账户选择 + **创意组概念（每组 8 视频，创意 1~8 子 tab）**；我们是「1素材1链路」轮转 → 若要对齐需引入「创意组×N视频」分组模型
8. **文案库带 3日/30日消耗列 + 分组/创作者筛选 + 新建文案**；我们的文案是纯文本框
9. **预览区三层树表（计划→组→创意）+ 全部提交审核 + 删除/重命名/仅看失败**；我们目前只有确认弹窗 → 这是提交前的核心确认界面，值得做
10. 命名通配符（+账户ID/+账户备注/+应用名称 + 插入更多）与自动截断、动态标号起始值
11. 底部附加：优先应用商店 / 高级创意（模板选择）/ 直达链接（魔力链站，白名单）
12. 下载方式与资产组的联动：资产组开启→下载方式行隐藏、出现[选择资产组]；直接下载才有「优先应用商店」
